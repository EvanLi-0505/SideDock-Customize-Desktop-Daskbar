# SideDock v3.0.0 测试范围（Test Scope）

| 项目 | 内容 |
| --- | --- |
| 产品 | SideDock：保留 Windows 原生任务栏的侧边停靠栏（便携版） |
| 版本 | v3.0.0 |
| 测试包 | `SideDock_3.0.0_x64_portable.zip`（GitHub Releases） |
| 文档用途 | 说明本轮测试测什么、不测什么、在什么环境测、怎样反馈问题 |

---

## 1. 测试目标

1. 验证 v3.0.0 全部功能在常见 Windows 环境下可用、行为符合预期。
2. 重点验证 3.0.0 新功能：**窗口闪烁提醒、文件夹堆栈、启动台搜索增强、备份与恢复**。
3. 验证软件**不会破坏用户桌面**：任务栏能恢复、桌面图标不被重排（除非用户主动选择“从不隐藏”）、不在程序文件夹以外乱写文件。
4. 验证异常情况下的稳定性：重复启动、强制结束、资源管理器重启、睡眠唤醒、多显示器变化。

---

## 2. 测试环境

### 2.1 必测环境

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 11 x64（23H2 / 24H2 任一），Windows 10 x64 22H2 |
| WebView2 | Windows 11 自带；Windows 10 需确认已安装 WebView2 Runtime |
| 账户 | 普通用户账户（**不要**以管理员身份运行 SideDock） |
| 系统语言 | 简体中文、英文各至少一台 |
| 输入法 | 至少一台装有微软拼音（中文输入法测试用） |

### 2.2 建议覆盖的差异

- **缩放**：100%、125%、150%、175%
- **分辨率 / 比例**：1920×1080（16:9）、2560×1600（16:10）
- **多显示器**：至少一组双屏，包括主副屏缩放不同的情况
- **设备**：笔记本（有电池、Wi-Fi、蓝牙）和台式机（有线网络、无电池）各一台
- **原生任务栏位置**：底部（默认），可选测试“任务栏自动隐藏”已开启的系统

### 2.3 测试前准备（必读）

1. 把 zip 解压到一个**全新的空文件夹**，并且这个文件夹要有写入权限（例如 `D:\Test\SideDock`），**不要**放在 `C:\Program Files`。
2. `SideDock.exe` 和 `sidedock_tray.dll` 必须在同一个文件夹里。
3. 所有数据都在 exe 旁边的 `data` 文件夹里。**日志在 `data\logs`**，反馈问题时需要附上当天的日志。
4. **测试结束恢复方法**：在系统托盘的 SideDock 图标上右键退出，原生任务栏会自动恢复。不要只用任务管理器结束其中一个 `SideDock.exe` 进程：有两个同名进程，其中一个是守护进程。
5. **注意以下操作会影响桌面**，请在可接受的测试机上进行：
   - 停靠栏的自动隐藏设为 **“从不”** 会占用屏幕空间，Windows 可能重排桌面图标；
   - **“隐藏 Windows 任务栏”** 会隐藏原生任务栏，退出 SideDock 后会恢复；
   - **“Win 键接管”** 需要一次管理员授权（UAC），并会创建计划任务 `SideDock Win Key`；
   - 启动台底栏的**关机 / 重启 / 注销**会真的执行（需要再点一次确认）。

## 4. 不在本轮范围内（Out of Scope）

- Windows 7 / 8 / 8.1、32 位系统、ARM64 设备
- 安装程序或卸载程序（本软件只有便携版）
- 代码签名与 SmartScreen 提示（未签名的 exe 首次运行可能出现“Windows 已保护你的电脑”，属于已知情况）
- 杀毒软件误报的处理（可以记录，但不作为缺陷）
- 把应用**拖放**到文件夹堆栈上（本版本只支持右键菜单管理）
- 同一台电脑上多个 Windows 用户同时运行
- 源代码构建与开发环境

## 6. 缺陷反馈要求

### 6.1 每个问题请提供

1. **标题**：一句话描述问题
2. **编号**：对应本文档的测试项编号（如 `D-05`），没有对应项写“其他”
3. **环境**：Windows 版本、缩放比例、分辨率、单屏还是多屏、系统语言
4. **复现步骤**：从启动开始，逐步写清楚
5. **预期结果 / 实际结果**
6. **复现频率**：必现 / 偶现（大约几次中出现一次）
7. **附件**：截图或录屏；`data\logs` 下**当天**的日志文件；涉及设置的问题请附 `data\config\settings.json`

> 提交前请确认附件里没有个人隐私内容（日志中可能包含托盘程序名称、窗口所属程序路径等信息）。

### 6.2 严重程度

| 级别 | 定义 | 例子 |
| --- | --- | --- |
| 致命 | 导致无法使用电脑或丢失数据 | 任务栏消失且无法恢复；桌面图标被打乱；设置全部丢失 |
